### ⚠️ Deviation found and fixed

- **Gate ❌ on the first run:** `columns.tsx(48,22): TS2538: Type 'undefined' cannot be used as an index type`.
- **Cause:** `role` has a default in `UserBase`, so OpenAPI marked it optional and the generated type was `role?: Role`.
- **Fix:** redeclared `role: Role` (no default) on `UserPublic`, following the existing "id is always required" pattern, then regenerated the client. No migration was needed because no table changed.
- **Gate ✅ on re-run:** type check passed, lint clean, no `is_superuser` in `frontend/src` or `frontend/tests`.
- **Skill improved:** `reference/backend.md` §2 now includes `role: Role` on `UserPublic`, so future runs won't hit this.
